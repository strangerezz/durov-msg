# DUROV MSG

**Анонимный мессенджер** — без номеров телефонов, без e-mail, без следа.
Своё апп, которое выглядит как Telegram, но работает анонимно.

## Возможности

- 💬 **Личные сообщения с End‑to‑End шифрованием** — ECDH (P-256) + AES-GCM прямо в браузере. Сервер хранит только шифротекст.
- 👥 **Группы** и 📢 **каналы** (в канале писать может только владелец).
- 🫥 **Изюминка — «Призрачные сообщения»**: сообщения тают по таймеру или после N просмотров и полностью удаляются со всех устройств и с сервера.
- 🎆 **«Атмосфера чата»**: у каждого чата своя живая анимация фона (аврора, звёзды, дождь, сердечки, матрица) — такой фичи нет нигде.
- 🎬 **Гифки и стикеры** — анимированные эмодзи, а также отправка по ссылке.
- 🎤 **Голосовые сообщения** — запись прямо в чате (MediaRecorder).
- 📇 **Ник-карточки** — красивая карточка контакта одной кнопкой.
- ↪️ **Пересылка сообщений** между чатами одним кликом (с отметкой «Переслано из…»).
- 🔎 **Поиск по чату** — с подсветкой совпадений.
- 🗓️ **Разделители дней** в сообщениях.
- ⚙️ **Настройки под себя**: тёмно‑серая/светлая/авто темы, акцентный цвет, форма пузырей, масштаб текста, звуки, экспорт чата.
- 🔍 Поиск пользователей по нику, реакции, реплаи, редактирование и удаление сообщений, часы прочтения ✓✓, индикатор «печатает», уведомления в системе.
- 😎 **Эмодзи перед ником** + аватарки (загрузка своей картинки).
- 🎨 Иконка и логотип приложения — сгенерированный арт (файл `desktop/icon.png`).

## Запуск (веб-версия)

```bash
cd durov-msg
npm install --omit=dev
npm start
```

Открой **http://localhost:9173** в браузере. Открой в двух окнах/устройствах — и переписывайся.

## Запуск на Linux (CachyOS и др.)

```bash
./scripts/run.sh
```
Открой http://localhost:9173

## Настольная версия (exe / AppImage)

```bash
# Linux → AppImage
./scripts/build-linux.sh

# Windows → portable .exe (можно собирать и с Linux)
./scripts/build-win.bat
```

Готовые файлы появятся в `dist/`. AppImage запускается из-под CachyOS:
```bash
./dist/DUROV\ MSG-*.AppImage
```

## Структура

```
server/          Node.js + WebSocket сервер (Express + ws, JSON-хранилище)
public/          Веб-клиент (HTML/CSS/JS)
  js/crypto.js   E2E-шифрование (WebCrypto)
desktop/         Electron-обёртка, иконки, сборка
scripts/         Скрипты запуска и сборки
data/            Хранилище (создаётся автоматически)
```

## Про анонимность

- Регистрация = только псевдоним + крипто-ключ на устройстве. Ни номера, ни почты.
- ЛС шифруются на устройстве (E2E); сервер видит только шифротекст.
- Призрачные сообщения физически удаляются с сервера после прочтения/таймера.
- Для максимальной анонимности запускай сервер за Tor/VPN/свой сервер — локально всё живёт только у тебя.
