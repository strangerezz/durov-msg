# DUROV MSG

**Анонимный мессенджер** — без номеров телефонов, без e-mail, без следа.
Своё апп, которое выглядит как Telegram, но работает анонимно.

## Возможности

- 💬 **Личные сообщения с End‑to‑End шифрованием** — ECDH (P-256) + AES-GCM прямо в браузере. Сервер хранит только шифротекст **в ЛС**; в группах и каналах текст хранится открытым (как в классических мессенджерах).
- 🔐 **Подписанные токены** (HMAC-SHA256) — подделать чужой токен по uid больше нельзя, захват аккаунта закрыт.
- 🔑 **Резервная копия ключа** — экспорт секретного ключа + токена в файл, зашифрованный паролем (PBKDF2 + AES-GCM). Потеря устройства ≠ потеря доступа.
- ✅ **Счётчики непрочитанных** — персистентные, синхронизируются между вкладками и устройствами, сбрасываются при чтении.
- 🕘 **Пагинация** — «Загрузить старые сообщения», а не только последние 120.
- 🔎 **Поиск по сообщениям на сервере** — находит и в старых, не только в загруженных.
- ⬆️ **Медиа/файлы через HTTP-аплоад** — картинки, файлы и голосовые больше не упираются в лимит WebSocket (до 64 МБ).
- 🫥 **Призрачные сообщения с таймером переживают рестарт сервера** — загруженные файлы таких сообщений удаляются со следом.
- 👥 **Группы** и 📢 **каналы** (в канале писать может только владелец).
- 👤 **Внутренняя экономика (звёзды ⭐)** — у каждого нового аккаунта стартовый баланс 700⭐. Можно тратить и зарабатывать (бонус 10% при отправке подарка другу − _скидка при оплате_ +25⭐).
- 🎁 **Подарки** — 12 видов с лимитами (общий тираж / лимит на пользователя), можно покупать, дарить, выводить обратно звёздами и **апгрейдить в NFT**.
- 🛍️ **NFT-коллекции** — 9 эксклюзивных username (владелец `strangerezz`), продажа на аукционах с шагом ставки 50, buy-now ценой мгновенной покупки, фикс продавца 10%. Купленный NFT можно продать/перепродать в пул, вывести в свой username или снять с аукциона и получить.
- 🔑 **Резервированные username** — `strangerezz` нельзя зарегистрировать обычным способом (только владелец по секретному коду `OWNER_CODE`).
- 🫥 **«Призрачные сообщения»**: сообщения тают по таймеру или после N просмотров и полностью удаляются со всех устройств и с сервера.
- 🎆 **«Атмосфера чата»**: у каждого чата своя живая анимация фона (аврора, звёзды, дождь, сердечки, матрица) — такой фичи нет нигде.
- 🎬 **Гифки и стикеры** — анимированные эмодзи, а также отправка по ссылке.
- 🎤 **Голосовые сообщения** — запись прямо в чате (MediaRecorder).
- 📇 **Ник-карточки** — красивая карточка контакта одной кнопкой.
- ↪️ **Пересылка сообщений** между чатами одним кликом (с отметкой «Переслано из…»).
- 🔎 **Поиск по чату** — с подсветкой совпадений.
- 🗓️ **Разделители дней** в сообщениях.
- ⚙️ **Настройки под себя**: тёмно‑серая/светлая/авто темы, акцентный цвет, форма пузырей, масштаб текста, звуки, экспорт чата.
- 🔍 Поиск пользователей по нику, реакции, реплаи, редактирование и удаление сообщений, часы прочтения ✓✓, индикатор «печатает», уведомления в системе.
- 😎 **Эмодзи перед ником** + аватарки (загрузка своей картинки).
- 🎨 Иконка и логотип приложения — сгенерированный арт (файл `desktop/icon.png`).

## Запуск (веб-версия)

```bash
cd durov-msg
npm install --omit=dev
npm start
```

Открой **http://localhost:9173** в браузере. Открой в двух окнах/устройствах — и переписывайся.

## Запуск на Linux (CachyOS и др.)

```bash
./scripts/run.sh
```
Открой http://localhost:9173

## Настольная версия (exe / AppImage)

```bash
# Linux → AppImage
./scripts/build-linux.sh

# Windows → portable .exe (можно собирать и с Linux)
./scripts/build-win.bat
```

Готовые файлы появятся в `dist/`. AppImage запускается из-под CachyOS:
```bash
./dist/DUROV\ MSG-*.AppImage
```

## Структура

```
server/          Node.js + WebSocket сервер (Express + ws, JSON-хранилище)
public/          Веб-клиент (HTML/CSS/JS)
  js/crypto.js   E2E-шифрование (WebCrypto)
desktop/         Electron-обёртка, иконки, сборка
scripts/         Скрипты запуска и сборки
data/            Хранилище (создаётся автоматически)
```

## Про анонимность

- Регистрация = только псевдоним + крипто-ключ на устройстве. Ни номера, ни почты.
- ЛС шифруются на устройстве (E2E); сервер видит только шифротекст. **В группах и каналах текст открыт на сервере** — это честное отличие, как в Telegram.
- Призрачные сообщения физически удаляются с сервера после прочтения/таймера (вместе с загруженными файлами).
- Медиафайлы (картинки/голосовые/файлы) лежат на сервере, но **ссылки на них внутри ЛС зашифрованы** E2E, как и в остальных мессенджерах.
- Для максимальной анонимности запускай сервер за Tor/VPN/свой сервер — локально всё живёт только у тебя.
